## What I Understood

### Image Contrast

- **Contrast** = the difference between the brightest and darkest parts of an image
- **High contrast** → large intensity difference → edges and details stand out clearly → good for detection
- **Low contrast** → pixel values clustered in a narrow range → image looks flat and dull → details are hard to separate
- Contrast is critical in computer vision — the more clearly objects stand out from the background, the more accurately they can be detected

### Image Histograms

- A histogram is a bar chart showing how many pixels have each intensity value (0 to 255 for 8-bit grayscale)
- Reading a histogram reveals the character of an image:
  - Bars concentrated on the **left** → underexposed / too dark
  - Bars concentrated on the **right** → overexposed / too bright
  - **Narrow spread** → low contrast
  - **Wide spread** → higher contrast
- Histograms are a quick diagnostic tool before applying any processing

### Histogram Equalization

- Redistributes pixel intensity values across the full range (0–255) to improve contrast automatically
- Stretches a narrow histogram to span the full width
- Result: previously hard-to-distinguish details become more visible
- Useful when contrast is poor due to lighting conditions

### Convolution Filters — Summary

| Filter | Main Use | Handles Noise Type |
|---|---|---|
| Gaussian | Smooth, reduce noise | Gaussian noise |
| Median | Noise removal, edge-preserving | Salt-and-pepper noise |
| Sobel | Edge detection (gradient) | — |
| Laplacian | Edge detection (second derivative) | — |
| Sharpening | Enhance edges and fine details | — |

### How Filters Work

- Every spatial filter uses a **kernel** — a small matrix slid across the image
- At each pixel, the kernel values multiply the surrounding pixel values and the results are summed
- The kernel shape determines what the filter does:
  - **Averaging kernel** → blurs (smooths)
  - **Gaussian kernel** → weighted blur, more natural-looking smoothness
  - **Edge kernel (Sobel/Laplacian)** → highlights areas of rapid intensity change

## My Reflection

- Histograms are more useful than I thought — just looking at the shape immediately tells you a lot about an image's quality
- Histogram equalization is a clever trick — the image doesn't change but the contrast becomes much better automatically
- Understanding filters as kernels that perform convolution made me realize all these operations follow the same underlying mathematical idea — only the kernel values differ
- For my bird counting project, I now have a clear processing chain in mind: Gaussian blur to remove noise → Sobel edge detection → thresholding → connected component labeling to count the birds
