## Pre-Reading Reflection Note – JavaFX 8

While reading the **JavaFX 8** chapters, I learned that JavaFX is used to create graphical and interactive applications in Java. I first came across the basic concepts of **Stage, Scene, and Scene Graph**. I understood that the **Stage is the main window, the Scene is the content area inside the window, and the Scene Graph is a hierarchical structure that organizes all the elements placed inside the Scene**. I also learned that different layouts can be used to arrange these elements. For example, **VBox arranges elements vertically, HBox arranges them horizontally, and GridPane arranges them in rows and columns like a table**. These concepts helped me understand how different components such as buttons, labels and text fields can be organized to create a proper user interface.

While studying, some questions came to my mind: **What is the difference between a Stage and a Scene? Why is the Scene Graph organized like a tree? How do different nodes interact with each other? How does JavaFX know what should happen when I click a button? How do VBox, HBox and GridPane decide where to place different components?** I was also curious about **Scene Builder and FXML**, and why they are useful when the same interface can be created using Java code. Overall, this reading helped me understand that JavaFX is not just about creating the visual appearance of an application; it provides a structured way to **organize, control and interact with different elements of a graphical application**.

## Reflection Note – AWT, Swing and JavaFX

While exploring Java GUI programming, I came across **AWT, Swing, and JavaFX**. I understood that all three are used to create graphical user interfaces in Java, but they belong to different stages of Java development. **AWT (Abstract Window Toolkit)** is an older GUI toolkit that provides basic components and graphics, while **Swing** provides more flexible and customizable components and is built on top of AWT. **JavaFX** is a newer framework that provides features for creating richer and more interactive interfaces.

This made me curious about **why Java needed Swing after AWT and why JavaFX was introduced after Swing**. I also wondered about the differences between components such as an AWT `Frame`, Swing `JFrame`, and JavaFX `Stage`. At this point, I have a basic understanding that they represent different approaches to creating Java GUI applications, but I would like to understand more about **how their architecture, components, event handling, and graphics capabilities differ**.
