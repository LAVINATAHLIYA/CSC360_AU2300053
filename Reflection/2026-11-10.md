## What I Understood

### Reading Images in Java with `BufferedImage`

- `ImageIO.read(new File("image.jpg"))` loads an image into a `BufferedImage` object
- `BufferedImage` stores pixel data as an array of integers (ARGB format by default in Java)
- Each pixel integer contains all four channels packed together: `0xAARRGGBB`
- To read a pixel: `int pixel = image.getRGB(x, y);`
- Extracting individual channels using bit masking:
  - Red: `(pixel >> 16) & 0xFF`
  - Green: `(pixel >> 8) & 0xFF`
  - Blue: `pixel & 0xFF`
  - Alpha: `(pixel >> 24) & 0xFF`

### Implementing Grayscale Conversion

- For every pixel, extract R, G, B values and compute: `gray = (int)(0.299*R + 0.587*G + 0.114*B)`
- Create a new pixel with the same gray value in all three channels: `0xFF000000 | (gray << 16) | (gray << 8) | gray`
- Write back to a new `BufferedImage` using `outputImage.setRGB(x, y, newPixel)`
- Result is a grayscale image that looks correct to the human eye (green-weighted, not simple average)

### Implementing Gaussian Blur

- Create a Gaussian kernel (e.g., 3×3 or 5×5) with appropriate weights
- For each pixel, multiply the kernel values with the corresponding neighbouring pixels and sum the results
- Handle **border pixels** carefully — options: skip them, mirror the border, or pad with zeros
- After applying the blur, the image is visibly smoother and noise is reduced

### Testing on Garden Images

- Tested the pipeline on a few sample garden images with birds
- After grayscale conversion, the birds showed up at clearly different intensities from the green grass
- After Gaussian blur, random noise pixels disappeared
- The birds were still clearly visible as distinct darker or lighter regions — the preprocessing worked well
