## What I Understood

### JavaFX Scene Builder and FXML

- Scene Builder is a drag-and-drop tool for designing JavaFX UIs visually
- It generates an **FXML file** — an XML-based description of the UI layout
- The controller class is then linked to the FXML file using the `@FXML` annotation
- This separates the **look** (FXML) from the **behavior** (Java controller)
- The benefit is that designers can work on the UI while developers handle the logic

### Observable Properties

- JavaFX provides `Property` classes like `StringProperty`, `IntegerProperty`, `ObjectProperty`
- These are **observable** — other parts of the app can listen for changes automatically
- **Binding** means linking a UI element's value directly to a property so the display updates on its own
- This removes the need to manually refresh the UI after every change

### ListView and Selection Model

- `ListView<T>` displays a scrollable list of items — the core of the master section
- The **selection model** tracks which item is currently chosen
- Adding a listener to `selectedItemProperty()` lets us react whenever the user picks a different item
- This is exactly how the master panel notifies the detail panel to update

### Lambda Expressions as Event Handlers

- Instead of writing a full anonymous class for every listener, Java lambdas make it concise:
  - `listView.getSelectionModel().selectedItemProperty().addListener((obs, old, newVal) -> updateDetail(newVal));`
- Lambdas make event-driven code much easier to read
