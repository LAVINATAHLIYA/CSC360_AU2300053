# Reflection — September 3, 2026

## Topics Discussed

* We started the class by discussing **ASCII trees** and how a tree structure can be represented using characters and text.

  * We looked at the different characters required to create an ASCII tree and how the structure is represented visually through text.
  * We also discussed the difference between **printing a tree** and **drawing a tree**, especially in terms of how text and graphics represent information.

* We compared **text-based interfaces and graphical interfaces**.

  * Text/command-line interfaces are generally simple, fast, lightweight, and robust.
  * Graphical interfaces are more visual and easier for users to understand in many situations, but they can require more resources.
  * This led to a broader discussion about whether the command line or graphics are more powerful and why text remains an important method of computing.

* We discussed the idea of **converting an image into text**, referred to as the **ORS process**, and how visual information can be represented using characters.

  * This helped connect the concepts of digital images, text representation, and computer graphics.

* We discussed what a **console/CLI (Command Line Interface)** is and why the **terminal** is useful.

  * The terminal provides a direct way of interacting with the computer through commands.
  * It is particularly useful for navigating directories, managing files, connecting to remote systems, and performing tasks efficiently.

* We explored how a **directory can be represented using an ASCII tree**.

  * A directory naturally has a tree-like structure because folders can contain subfolders and files.
  * However, when there are many nodes, representing everything as a traditional horizontal tree can become difficult to read.
  * A practical solution is to use **vertical lines and display the structure line by line**, making the hierarchy easier to follow.

* We also discussed **SSH (Secure Shell)** and how it can be used to connect to a remote server.

  * We looked at the basic process of establishing a remote connection and why SSH is useful when working with servers through the command line.

* Another topic was **thread termination and graceful cancellation**.

  * Instead of immediately stopping a running thread, graceful cancellation gives the thread an opportunity to finish its current work and shut down properly.
  * This is safer and more controlled than forcibly terminating a thread.

* We discussed the purpose of a **splash screen** in applications.

  * A splash screen appears while an application is starting and is an important part of the user experience.
  * It can display the **company/application logo, name, loading or progress information, and version number**.
  * The version information is especially useful because it helps identify which version of the application is currently running.

## Reflection

The discussion helped me understand that computer graphics and digital image processing are not limited to creating visual images. Even something as simple as representing a tree using ASCII characters involves thinking about structure, representation, readability, and computation. The comparison between text and graphics also made me think about how powerful and robust text-based computing can be, especially through the command line and terminal.

The discussions on SSH, thread cancellation, directory structures, and splash screens also showed how these concepts connect to practical software systems. Overall, the class gave me a broader understanding of how different forms of representation and interaction are used in computing, from simple text-based structures to graphical user interfaces.
