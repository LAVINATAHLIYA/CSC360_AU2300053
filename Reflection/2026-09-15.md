## What I Understood

### Checking if Three Points Form a Triangle

- Three points form a triangle only if they are **not collinear** (not on the same straight line)
- Use the formula: `D = x₁(y₂ − y₃) + x₂(y₃ − y₁) + x₃(y₁ − y₂)`
- If `D = 0` → points are collinear → not a triangle
- If `D ≠ 0` → they form a triangle
- Since we use `double` values, we should use a small tolerance (`EPSILON`) instead of checking for exact zero

### Finding Intersection of Two Lines

- Write two lines as: `a₁x + b₁y = c₁` and `a₂x + b₂y = c₂`
- Calculate determinant: `D = a₁b₂ − a₂b₁`
- If `D ≠ 0` → lines intersect at one point: `x = (c₁b₂ − c₂b₁) / D` and `y = (a₁c₂ − a₂c₁) / D`
- If `D = 0` → lines are either **parallel** (no intersection) or **coincident** (infinite intersections)

### Representing Three Lines as `Ax = b`

- Three line equations can be written as a matrix system where `A` is 3×2, `x` holds unknowns, and `b` holds constants
- Three lines don't always share one common point — they can intersect in pairs at different locations, be parallel, or be coincident
- To check a common intersection: find intersection of any two lines and verify the point satisfies the third

### JavaFX UI with GridPane

- `GridPane` is used to arrange the input form in a row-column table layout
- 9 `TextField` fields for entering line coefficients, plus labels, buttons, and a result display area
- Validation is done before calculation — empty fields, invalid numbers, `NaN`, `Infinity`, and zero-coefficient lines are all checked

### Project Structure (Clean Separation)

- `Application` → starts the JavaFX program
- `Controller` → handles user input and shows results
- `Model` → represents lines and points
- `Service` → performs all geometry calculations (pure logic, no UI)
- This separation makes the code much easier to test and maintain
