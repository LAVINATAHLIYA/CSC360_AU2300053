## What I Understood

### Data Model Design

- The entity class (e.g., `Student`, `Product`) should be a plain Java object (POJO) with clean getters/setters
- Using JavaFX `Property` types (like `SimpleStringProperty`) in the model enables direct binding to UI fields
- Keeping the model free of JavaFX code makes it easier to test independently

### `FilteredList` and `SortedList`

- `FilteredList<T>` wraps an `ObservableList<T>` and applies a **predicate** to show only matching items
- Changing the predicate dynamically updates the visible items in the `ListView` or `TableView` automatically
- `SortedList<T>` wraps a list and applies a **comparator** for ordering items
- Chaining them: `ObservableList → FilteredList → SortedList → TableView` gives search + sort for free

### Implementing Live Search

- Attach a listener to a `TextField` for the search input
- On every keystroke, update the `FilteredList` predicate to match the current search text
- The table or list view instantly reflects the filtered results — no button click needed
- Case-insensitive search: `item.getName().toLowerCase().contains(searchText.toLowerCase())`
