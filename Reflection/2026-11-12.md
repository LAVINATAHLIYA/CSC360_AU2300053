## What I Understood

### Implementing Otsu's Thresholding in Java

- Build a histogram of pixel intensities from the grayscale image (256 bins, 0–255)
- For every possible threshold value (0 to 255), calculate the **between-class variance**
- Choose the threshold that **maximizes** the between-class variance — this cleanly separates foreground and background
- Apply the threshold: pixels with intensity above the threshold → 255 (white / foreground); below → 0 (black / background)
- Result is a **binary image** where birds appear as white regions on a black background (or vice versa depending on intensity)

### Sobel Edge Detection

- Apply two Sobel kernels — Gx (horizontal gradient) and Gy (vertical gradient) — to the grayscale (or thresholded) image
- At each pixel: `magnitude = √(Gx² + Gy²)` — high magnitude means a strong edge
- Threshold the magnitude image to get a clean binary edge map — pixels above the edge threshold are edges, rest are zero
- Bird outlines appear as bright rings/curves in the edge map

### Connected Component Labeling (Counting Birds)

- In the binary image, scan every pixel
- When an unvisited white pixel is found, start a **flood fill (BFS/DFS)** to mark all connected white pixels as the same region
- Assign each region a unique label
- Count the total number of labeled regions = **candidate bird count**
- Filter regions by area:
  - **Too small** (fewer than ~20 pixels) → noise blob, ignore
  - **Too large** (larger than a reasonable bird size) → tree canopy or bush, ignore
  - Remaining regions → counted as birds

### Filtering False Positives

- Birds must fall within a realistic pixel area range for the image resolution
- Regions with unusual aspect ratios (very wide or very tall) can also be filtered out
- Combining edge strength with region size gives better discrimination between birds and background objects

### Displaying Results

- For each detected bird region, draw a **bounding rectangle** on the original colour image
- Display the bird count as text overlaid on the image
- Save the annotated image using `ImageIO.write(outputImage, "PNG", new File("output.png"))`

## My Reflection

- Implementing Otsu's method was the most mathematical step so far — iterating through all 256 threshold values and computing variance for each felt slow conceptually, but it runs extremely fast in practice
- Watching the connected component labeler actually count the birds on a test image was genuinely satisfying — seeing the pipeline go from a raw photo to a counted result
- The size filtering step is where most of the tuning happens — the minimum and maximum area thresholds need to be adjusted for different image sizes and bird sizes
- The hardest case I found was two birds sitting very close to each other — they merged into one region and got counted as one bird; solving this would need more advanced techniques like the watershed algorithm
- Overall, this project has connected almost every digital image processing concept from the course into one real, working application — grayscale conversion, filtering, contrast enhancement, thresholding, edge detection, and region analysis all come together here
- I feel much more confident reading and writing image processing code in Java after implementing each step from scratch rather than relying on a library to do it automatically
